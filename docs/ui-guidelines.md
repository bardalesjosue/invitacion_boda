# UI Design System Guidelines - Wedding Invitation Platform

This document describes the premium visual identities and variables implemented in the user interface.

## Color Palette

Minimalist and elegant color specifications:

- **Cream (Marfil)**: `#F9F7F2` (Used as warm backgrounds and details)
- **Olive Green (Verde Oliva)**: `#6B7A52` (Primary color, accents, and dividers)
- **Gold (Dorado)**: `#C9A227` (Highlighting luxury details and premium buttons)
- **Gray (Gris)**: `#666666` (Subtle text and metadata)
- **Black (Negro)**: `#222222` (Deep backgrounds and administrative contrasts)

## Typography

Refined text configurations:

- **Titles**: `Cormorant Garamond` (Sophisticated serif typeface loaded from Google Fonts).
- **Paragraphs / Inputs**: `Lato` or `Inter` (Legible sans-serif typefaces for text details).

---

## Design System Elements

### 1. Button Variants

- **Primary**: Black backings with Gold borders.
- **Secondary**: Cream backgrounds.
- **Gold**: Full luxury metallic background, dark text.
- **Outline**: Transparent border, gold text.

### 2. Glassmorphism Panels

- **Dark Panels**: `rgba(34, 34, 34, 0.6)` with backdrop-filter blur and subtle gold border borders.
- **Light Panels**: `rgba(249, 247, 242, 0.65)` for clear, daytime contrast.
